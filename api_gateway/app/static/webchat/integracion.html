Integración

Cómo agregarlo a tu página

Cada cliente tiene su canal Chat web en la consola (sección Canales), con su clave pública (wc_…) y el fragmento listo para copiar. Tres pasos: cargar el CSS y el JS del widget, definir la configuración antes de que el script corra, y listo — se auto-inicializa solo.

1

Cargá el CSS y el script del widget

Van en cualquier parte de tu <head> o antes de cerrar </body>. Se sirven desde nuestro dominio, no hace falta alojarlos vos.

<link rel="stylesheet" href="https://chat.flowsdone.com/agent-chat-widget.css" />
<script src="https://chat.flowsdone.com/agent-chat-widget.js"></script>
2

Definí window.AgentChatConfig antes del script

El widget busca esta variable global apenas carga y se auto-inicializa. El único campo obligatorio es channelKey, la clave del canal Chat web del cliente. Si el canal tiene dominios permitidos, el chat solo funciona en esas webs.

<script>
  window.AgentChatConfig = {
    wsUrl: "wss://chat.flowsdone.com/ws",
    channelKey: "wc_TU_CLAVE",      // obligatorio: la clave del canal Chat web
    title: "Mi Asistente",
    initialMessage: "¡Hola! ¿En qué te puedo ayudar?",
    launcherColor: "#4F46E5",
    sendButtonColor: "#10B981"
  };
</script>
<link rel="stylesheet" href="https://chat.flowsdone.com/agent-chat-widget.css" />
<script src="https://chat.flowsdone.com/agent-chat-widget.js"></script>
3

(Opcional) Inicializá manualmente

Si preferís no usar window.AgentChatConfig — por ejemplo, para crear el widget después de una acción del usuario — llamá a init() a mano con el script cargado con defer.

<script defer src="https://chat.flowsdone.com/agent-chat-widget.js"></script>
<script>
  window.addEventListener("load", function () {
    window.AgentChat.init({ wsUrl: "wss://chat.flowsdone.com/ws", channelKey: "wc_TU_CLAVE" });
  });
</script>
Referencia

Variables de configuración disponibles

Todo lo que acepta AgentChatConfig / AgentChat.init(options), agrupado por para qué sirve. Ninguna es obligatoria salvo channelKey.

Conexión

VariableDefaultQué hace
channelKey—Obligatorio. Clave pública del canal Chat web del cliente (wc_…), en la consola → Canales. Decide qué agente responde; las conversaciones cuentan como las de cualquier canal.
wsUrlautoEndpoint del WebSocket. Por defecto se arma a partir del dominio de la página (wss://tu-dominio/ws), así que en la web del cliente hay que indicarlo: wss://chat.flowsdone.com/ws (el fragmento de la consola ya lo incluye).
sessionIdautoId de sesión del visitante. Se genera y persiste en localStorage si no lo pasás.
conversationIdautoId de conversación, también persistido en localStorage. Pasalo vos si necesitás controlar cuándo empieza una conversación nueva.
